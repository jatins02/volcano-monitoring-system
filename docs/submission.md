# Submission and release workflow

Run `make check`, `make test-acceptance`, and the browser suite described in tests/e2e/README.md. Commit the verified sources/evidence locally before packaging. `make submission` packs every tracked regular file and a generated SUBMISSION-MANIFEST.json into `build/submission/volcano-monitoring-system.tar.gz`. gzip/tar timestamps, ownership and order are normalized; identical tracked bytes/modes produce identical archive bytes. It verifies every archived file hash before returning. Ignored runtime, dependency directories and the session handoff are excluded. The archive is a source/evidence submission, not a bundled operating system/toolchain.

Include the root context/staged plan and AGENTS, specs, native .circ/core-map/output schema, assembly .s/generated include, Python coordinator, React/TypeScript/CSS/local SVG sources, all locks/tool manifests, fixtures, scripts, curated traces/screenshots, academic report, final warning report and demo script. The generated manifest lists every packaged path/hash. No proprietary Canva design is redistributed; its link/observations remain reference material.

Reproduction prerequisites: Linux x86_64, GCC/binutils/Make, Python3.12–3.14 with venv/pip. `make bootstrap` installs pinned project-local runtimes/npm/Python packages using official sources. See tools/README.md and tools/toolchain.json for exact URLs and SHA256. Then `make doctor` and `make run` build fresh binaries/assets and serve127.0.0.1:8000 using one worker. Development uses separate terminals `make dev-api` and `make dev`, with/api proxied from5173. There is no wildcard CORS. Unknown API/assets and traversal do not enter the SPA fallback. All runtime assets are local.

Offline operation requires bootstrap to have completed. Installed dependencies support make run/test/evaluation without internet or Canva login; tools are not downloaded on each run. `make clean-generated` removes only build/ and frontend/dist/, preserving runtime/SQLite histories and installed dependencies. Stop owned servers first; the next make run rebuilds outputs. Do not delete runtime to resolve an evaluation failure; inspect logs, reset or create a new session.

`scripts/check_release.py` tests real same-origin assets/API/404/traversal and an actual DANGER job, then creates a clean local clone and rebuilds/tests offline using existing installed dependency directories. Its log states that scope explicitly. No second human test or network-isolated installation is claimed. Optional Stage13 remains deferred.
