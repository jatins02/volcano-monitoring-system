# Website behavior and provenance

`make dev-api` and `make dev` run the real coordinator and Vite proxy. All assets are local. The adapted Canva reference, observed in the plan, supplies the desktop-window motif; the chosen active title bar is #727eba. `frontend/qa-layout.html` is a dev-only viewport fixture and is excluded from Vite's production entry.

The controller separates editable string drafts, authoritative session history, immutable pending jobs, confirmed results, mismatch diagnostics and historical sample selection. No slider or animation event calls the API. Each Apply commits one complete row. Batch explicitly appends all scenario rows in one job; New empty session replaces the active view without deleting prior server sessions. Play submits one scenario row only after the previous comparison succeeds; Pause lets an accepted row finish. Reload restores the shared session without autoplay.409 refreshes stale tabs instead of applying their old draft. Reset uses a new generation and invalidates older awaits; an acknowledgement/reset race retries Reset against the refreshed revision.

`api.ts` validates transport shapes, integer widths, arrays and ordered snapshots. The backend remains responsible for full packed-protocol validation. A result is displayed only for its session/generation/revision/rule and pending input hash. Failed/mismatched jobs retain the last confirmed output, visibly labelled with its older revision. Retry adds no row. Missing dependencies are errors, never fallback calculations.

`visuals.tsx` renders the submitted SensorCheck, Validity, WarningLogic and WindowCounters architecture from the checked core-map names and returned fields. Bit extraction for probe presentation is not classification. No unexposed internal net is invented. The SVG is an architectural visualization, not an embedded Logisim editor. The .circ download opens in native Logisim; choose MonitorGUI. Circuit pan works by pointer or arrow keys, with bounded zoom and Reset view.

Volcano motion is illustrative and bounded: vibration is at most2.5 SVG units, temperature maps chamber hue, gas controls at most20 particles, activity changes one bounded contour/crack. A sample-index seed makes replay deterministic. requestAnimationFrame is cancelled on sample change/unmount and disabled by prefers-reduced-motion. Fault transport values remain visible numerically; drawing intensity caps at100. Animation never advances the sample clock or counters.

Assembly views show actual captured stdout/stderr, exit codes and packed rows, assembly-generated statistics, and exact six-bus comparison. Source and executable hashes must match the displayed job; browser SHA256 also verifies downloaded source bytes. Source is escaped React text, with line numbers and basic comment/directive coloring. Download monitor.s and rules.inc separately; preserve the assembly/ directory layout when building standalone. Code is read-only, without claimed instruction stepping.

History selects stored per-sample hardware/native records and disables commits until Return live. Full-session stdout/statistics stay explicitly labelled with their revision; no prefix statistics are invented. JSON/CSV come from the server. Native text and printable HTML contain the confirmed revision/provenance; HTML escapes all output. Browser print can produce PDF. No audio alarm is included; emergency is a labelled hardware indicator.
