# Website behavior and provenance

`make dev-api` and `make dev` run the real coordinator and Vite proxy. All assets are local. The adapted Canva reference, observed in the plan, supplies the desktop-window motif; the chosen active title bar is #727eba. `frontend/qa-layout.html` is a dev-only viewport fixture and is excluded from Vite's production entry.

The controller separates editable string drafts, authoritative session history, immutable pending jobs, confirmed results, mismatch diagnostics and historical sample selection. No slider or animation event calls the API. Each Apply commits one complete row. Batch explicitly appends all scenario rows in one job; New session replaces the active view without deleting prior server sessions. Play submits one scenario row only after the previous comparison succeeds; Pause lets an accepted row finish. Reload restores the shared session without autoplay.409 refreshes stale tabs instead of applying their old draft. Reset uses a new generation and invalidates older awaits; an acknowledgement/reset race retries Reset against the refreshed revision.

`api.ts` validates transport shapes, integer widths, arrays and ordered snapshots. The backend remains responsible for full packed-protocol validation. A result is displayed only for its session/generation/revision/rule and pending input hash. Failed/mismatched jobs retain the last confirmed output, labelled as previous confirmed readings. Retry adds no row. Missing dependencies are errors, never fallback calculations.

`visuals.tsx` and `logic-diagram.tsx` render a fixed read-only digital schematic: four binary threshold outputs, validity AND gates, explicit zero extension, three three-bit adders, K comparators and warning output gates. For each sensor, the input is ON only above its fixed threshold (V70,T60,G65,A70). K is the sum of the four effective inputs: 0 gives NORMAL, 1 WATCH, 2–4 DANGER/emergency. Invalid rows force effective inputs OFF and separately report FAULT. Final probes and digital inputs come only from the selected hardware snapshot; intermediate pair sums/comparator indications illustrate the fixed equation. The component has no assembly-data interface or connection to the assembly panel. The existing backend still evaluates both tools independently and compares their results.

Signal wires use green for ON/nonzero, dark green for OFF/zero, and dashed gray for unknown. Numeric labels supplement color. The native `.circ` download opens on the expanded `MonitorGUI`, with the actual numeric comparators and warning gates. The website drawing is not an embedded native editor. Pan works by pointer or arrow keys, with bounded zoom and Reset view. 10-reading counts remain available in an expandable detail section below the schematic.

Volcano motion is illustrative and bounded: vibration is at most2.5 SVG units, temperature maps chamber hue, gas controls at most20 particles, activity changes one bounded contour/crack. A sample-index seed makes replay deterministic. requestAnimationFrame is cancelled on sample change/unmount and disabled by prefers-reduced-motion. Fault transport values remain visible numerically; drawing intensity caps at100. Animation never advances the sample clock or counters.

The Code tab opens on a display-only teaching example from `assembly/teaching-example.s`. It is labelled as warning logic only, with line numbers, syntax coloring and copy/download controls. The example checks connectivity/range, counts strict threshold violations, and selects NORMAL/WATCH/DANGER/FAULT. It uses the shared `assembly/rules.inc`; assemble from the repository root with `gcc -c assembly/teaching-example.s -o /tmp/teaching-example.o`. It is never linked into or invoked by the application.

`assembly/monitor.s` remains the production analyser. Output selects its parsed native record for the displayed reading; Statistics shows its returned min/max/average, and Comparison shows the actual backend agreement. Hashes, process logs, raw packed buses and tool versions are absent from the page. Full evidence remains in API results, native text and report downloads; exact archived production source remains available at `/api/source/assembly?job=<job-id>`. Provenance checks remain in the controller/API boundary. A mismatch stays visible even while older confirmed results are retained.

The default controls emphasize Run/Step, Play, Pause and Reset. New session, Retry and Refresh live under Session options. Reading numbers, unsampled drafts, pending calculations, historical selection and previous results stay explicit, without session IDs, generation/revision labels or timing metadata.
History selects stored per-sample hardware/native records and disables commits until Return live. Statistics stay explicitly labelled as all N readings; no prefix statistics are invented. JSON/CSV come from the server. Native text and printable HTML contain the confirmed revision/provenance; HTML escapes all output. Browser print can produce PDF. No audio alarm is included; emergency is a labelled hardware indicator.

Circuit rectangles have single-line labels: `0 ext 1→3` preserves a binary input while widening it, `+ (3 bit)` adds two values, and `K = 0`, `K = 1`, `K > 1` compare the sum. The “What do the rectangular components do?” detail explains these operations. Native import and rendered layout were checked separately; see [verification](../reports/circuit-layout/verification.md).
