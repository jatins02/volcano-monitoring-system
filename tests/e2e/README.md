# Browser and end-to-end validation

Use two terminals: `make dev-api` and `make dev`. Open http://127.0.0.1:5173/qa.html and press Run browser checks. This development-only page drives actual React controls in an iframe, uses an isolated local-storage session key, and waits for actual Logisim/native comparison results. It does not inject fake results or use a production reference calculator. It is not included in the production Vite entry.

Ten automated groups cover drafts/synchronization, double Apply, NORMAL/WATCH/DANGER, confirmed-vs-draft isolation, historical side effects/statistics scope, batch tenth-sample/teaching-source behavior, fault/NO VALID DATA, serialized Play/Pause, reset in flight, export endpoint bodies and layout/digital logic groups at1366x768,1920x1080,390x844. Native keyboard input and narrow stacking were also inspected through browser accessibility tools.

`make test-web` runs seventeen isolated controller/transport/export/schematic regressions and formatting checks; fake transports there deliberately exercise race/failure cases. `make test-api` checks real missing dependencies, mismatch, process failure, restart, request identity, reset and retained confirmed output. `make test-acceptance` creates eight actual independently checked assignment cases and five benchmark repetitions per size1,10,100,600. Existing reports/stage7 failure artifacts and reports/stage11 browser/benchmark logs are curated evidence.

The suite is a browser page rather than a separate installed automation runner, avoiding an additional downloaded browser. Open it in a modern local browser; it requires the actual backend and installed toolchain. Additional clipboard/download UI checking stalled in the tool session, so those extra checks are not claimed passed. Endpoint contents, HTML escaping and production source availability and the teaching-example label are verified. No manual native Logisim desktop GUI screenshot is claimed.

The schematic tests render all 43 fixed threshold/truth/fault fixtures without assembly data, plus the unknown/empty state.
